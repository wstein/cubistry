# Cubistry Knowledge

This directory is a portable, Markdown-first knowledge base and an optional Obsidian vault. Git is the source of truth; Obsidian is a viewer/editor, not a runtime dependency.

## Navigate

- [Zettelkasten](zettel/index.md) — atomic insights and open questions
- [Maps of content](maps/index.md) — topic navigation
- [Architecture decisions](adr/index.md) — accepted/superseded decisions
- [Specifications](specs/index.md) — testable product and technical requirements
- [Plans](plans/index.md) — implementation approach
- [Milestones](milestones/index.md) — delivery outcomes
- [Tasks](tasks/index.md) — only durable task notes; use GitHub Issues for actionable work
- [Assets](assets/index.md) — locally owned illustrations and supporting media
- [Conventions](CONVENTIONS.md) — metadata, links, lifecycle and templates

## Existing evidence

The existing `docs/` and `results/` directories remain in place. Link to proof artifacts by relative Markdown links instead of moving or duplicating them. This vault does not imply that pending layout candidates are mathematically proven.
