# Cubistry

A browser-first engine for twisty-puzzle artwork and display states.

## First application: Chronocube

A 5×5×5 twisty-puzzle clock and calendar.

The initial mathematical feasibility spike investigates whether
one immutable sticker design can display:

- German and English weekday and month abbreviations
- Every valid calendar date from 2020 through 2049
- Every minute of the day (HH:MM)
- Physically reachable 5×5×5 cubie states

## Status

Experimental mathematical feasibility spike.
