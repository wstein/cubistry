# Counter sticker images and source-frame review

The physical witness supplies 24 labeled facelets with fixed source position,
normal, print-up vector, and image identity. The renderer creates one plane per
facelet, attaches it to its cubie, and maps local texture-up to the stored
print-up tangent. Cubie rotations then transform positions, normals, and images
together. Its geometry is checked independently of these images.

Numerals are SVG paths in the canonical 256×256 viewBox, generated by
`digitSvg()` in [the image adapter](../src/apps/counter/artwork.ts). A small bottom baseline
mark prevents cross-character rotational aliases such as 6 becoming 9.
The full 256×256 area has a uniform background; segment shapes and baseline
remain within the 40–236 pixel vertical safe area. Blank means the same background
without a printed glyph. Vector sources do not depend on installed digit fonts.

The configured title is laid out once on a 512×256 canvas and split into two
256×256 fragment images. Each image is cached once and shared by both physical
copies. The pinned 600-weight Noto Sans Latin font is loaded before rasterizing.
This is a virtual preview bitmap, not a production SVG/print export. The label
limits keep text readable and avoid silent clipping. Non-Latin browser fallback
may vary by operating system; the Latin font's license and source are recorded
in [the reuse audit](COUNTER_REUSE.md). There are no external image/font references.

Completed physical targets require all nonblank images upright. Browser tests
sample the numeric baseline from actual WebGL screenshot pixels, check that
upper-title pixels remain stable across different goals, and exercise a real
animated move sequence, camera drag/reset, and mobile layout. The local desktop
and mobile screenshots are test outputs, not a substitute for the physical
proof. Changing the title or numeric format uses an explicit new-print operation;
counting never redraws or changes an image.
