# Five-second timer

The **5-Second Timer** is a separate application with an immutable physical 2×2 print. Countdown defaults to 30:00; Stopwatch starts at 00:00. Its exact inclusive domain is **00:00–39:55**, in five-second steps. Durations such as 40:00 or 00:01 are rejected, never rounded. Stopwatch stops at 39:55 without wrapping. The existing 60-Minute Timer retains its ten-second resolution and 59:50 bound.

Both timers share the monotonic clock and physical playback framework. Countdown rounds partial intervals up; Stopwatch rounds completed intervals down. Pause preserves fractions, reset restores the configured duration (or zero in Stopwatch), and timer speed is independent of rotation speed. The inherited timer rotation default is 250 ms per HTM move; Counter retains 100 ms. Slow animation or accelerated time can make the physical cube lag. The synchronization indicator distinguishes logical time from the displayed physical state; playback finishes one active sequence and keeps only the latest requested target.

## Verified Research dependency

[The source pin](../five-second-source.json) identifies the exact commit and file hashes on `research/cube-display-feasibility`. That branch retains the proofs, search inputs/results, independent proof review and animation benchmarks. See its [maximum-range and optimization report](https://github.com/wstein/cubistry/blob/a768d810b483837a171d9cf8f94c3cc5c8ed868c/research/five-second-timer/README.md).

Run `npm run setup` for a fresh checkout. `npm run prepare:five-second` fetches only the pinned commit when verified cached files are absent, validates every selected SHA-256, and materializes ignored `.five-second-research/` evidence plus `public/five-second-timer.v1.json`. Dev, test, typecheck and build prepare this dependency automatically. A first preparation requires GitHub network access; an intact cache works offline. No Research history is merged into the feature branch, and no runtime solver or glyph substitution constructs the display.

The selected certificate covers 480 inclusive states / 479 edges, totaling 2,237 HTM, maximum 6 and mean 4.6701. A 30-minute countdown visits 361 states / 360 edges and commits 1,681 HTM. Initial configuration is excluded from those counts. The exact range is proven maximal under the documented fixed-print/upright model; global layout/traversal move optimality remains **UNKNOWN**. Local real-animation observations establish a sample budget, not a guarantee for all devices.

## Validation

```sh
npm run check
npm run test:e2e
```

`check` validates types, existing Counter/ten-second Timer regressions, production build, immutable Research certificates, corruption controls, full-range clock behavior and actual full-state controller traces. Browser tests exercise the full thirty-minute physical countdown, exact Stopwatch cap, invalid input, accessible responsive controls, application isolation and slow accelerated playback with pause/resume/reset. Run checks and browser tests sequentially: Playwright clears `test-results/` at startup, including controller trace fixtures generated by Node tests.
