These six whole-face vector illustrations (a gingerbread cookie, a snowman by a cottage, a reindeer under a lamp post and a teddy bear on a snowy night, with an aurora and a smiling star above and a lantern with gifts on a sled below) are a work separate from the
Cubistry program code, which stays under AGPL-3.0-or-later. The images are
licensed under CC BY-SA 4.0; the AGPL copyleft does not cover them. The SVG files in
this directory contain no text and no fonts; no third-party images, platform
glyphs, or stock artwork are included.

Editable source and regeneration:
  scripts/build-christmas-art.mjs
  node scripts/build-christmas-art.mjs      (rewrites the six faces)
  node scripts/build-playground-theme.mjs christmas   (re-pins them)

The art generator is the editable source of the artwork, so it is art data under
the same CC BY-SA 4.0 license, not AGPL program code.

Source repository: https://github.com/wstein/cubistry
License: https://creativecommons.org/licenses/by-sa/4.0/
Each whole face uses a 320 by 320 viewBox. The playground cuts the faces into the
N by N stickers a cube of size N needs when it loads them, so no pre-cut tiles are
stored.
